# Shared Cloudcourt font assets

Baloo2-Variable.ttf is Baloo 2 from Google Fonts, under the accompanying
Baloo2-OFL.txt. CloudcourtBubble.ttf is the static weight800 instance used by
the currently retained Cloudcourt releases. The family remains Baloo 2.
logo.png is original Cloudcourt artwork retained as an authoring dependency.
