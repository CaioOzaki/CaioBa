# Cloudcourt v28 own artwork and music

The startup emblem is reused from our original indoor flag design. Seven hats
are authored procedurally in build_customization_v28.py. Three original lofi
tracks are generated by build_settings_audio_v28.py from oscillators and
seeded noise only, with no third-party recordings or samples. Track generation
source is published; timings and file hashes stay in local delivery records. Generated WAVs are included locally
and inside the playable binary-difference package. Music is CC0 1.0 Universal.

No base-game mesh, texture, camera capture, photograph, binary patch or release
ZIP is stored in this source repository. The customization preview references
the user's separately owned installed avatar meshes at build/runtime.
