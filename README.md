# Cloudcourt VR - current v17 revision

Current release: **Cloudcourt-v17-revisao**. Fixes mirrored glove anatomy, tracked-hand NaN velocities during solo pause/resume, inactive wall score labels, stale skin packets that corrupt team membership, and buffered appearance RPC accumulation. Invalid motion frames are rejected before propagation. See [CHECKPOINT-V17-REVISAO.md](CHECKPOINT-V17-REVISAO.md).

Earlier v16 visual checkpoint: BOT 5 now has black hair, retaining her wine shirt and shoes. See [CHECKPOINT-V16-CABELO.md](CHECKPOINT-V16-CABELO.md). The updated installer is generated by `package_cloudcourt_hair_v16.py` and accepts the original compatible game or Cloudcourt v16. Online protocol is unchanged.

Cartoon VR volleyball mod, rebuilt from the explicitly selected **v15-rostos** baseline. Current design: https://www.figma.com/design/1sIgjKcMItHmbLIu1dnch0?node-id=2-24 . See [CHECKPOINT-V16.md](CHECKPOINT-V16.md) and [CLOUDCOURT-GAME-DESIGN.md](CLOUDCOURT-GAME-DESIGN.md).

This checkpoint uses the **Cloudcourt-2v2-v17 / Cloudcourt-4v4-v17** room namespaces. Abandoned experimental releases are retained in Git history; their exclusive files have been removed from the current branch. Do not mix their DLLs, generated assets, or installers with this checkpoint.

Native entry point: `spin_mod.c`, including `mode_2v2.c`, `formation_serve.c`, `online_2v2.c`, `comfort_v14.c`, `celebration_v15.c` and `identity_v16.c`. `build_patch.py` applies the compiled helper to the compatible local game copy. Tests execute compiled x64 code using deterministic Unity/Photon stubs.

Visual build: `create_cloudcourt_font.py` prepares the OFL Baloo 2 ExtraBold font; `create_puloviva_characters.py` (legacy technical filename) generates the current character meshes; `build_cloudcourt_v16.py` assembles menus, gloves, court, decorative antennas and wall boards. `fix_cloudcourt_menu_v16.py` also repairs title anchors and decorative raycast targets and replaces the shared VR loading logo. `fix_gloves_v16.py` and `fix_wall_boards_v17.py` repair handedness and scoreboard visibility. `fix_pause_v16.py` redirects only the tracked velocity/acceleration clock calls. `package_cloudcourt_v17.py` builds and tests the ten-file installer; it accepts the original compatible Steam build or Cloudcourt-v16-menu-corrigido. Earlier package scripts are preserved for their respective checkpoints.

Original procedural art and the open font/license live in `assets/cloudcourt-v16/`. `menu-figma.png` is the Figma direction, not a gameplay screenshot. The Unity adaptation uses the same identity with the existing VR UI structure.

Own compatible Volleyball Fever installation required (Steam build 9216628). Game binaries, extracted assets, backups, Mikasa art and installer ZIPs are not published. Build tools expect local `working`, `backup`, `versions`, `tools` and `characters-v16` folders; a clean clone alone is not a complete game build.

Automated tests, menu/indoor and beach startup checks and installer tests passed. Quest 3 gameplay and real two-PC multiplayer still need testing. Team switching respects capacity and is applied between points during a rally.

V17 validation: 17 focused/regression suites passed, including the actual original x64 pause/resume and velocity coroutine with controlled Unity APIs. The shipped DLL was also exercised. Menu/indoor startup remained active for 20 seconds; beach startup for 15 seconds. No headset was available, so these are initialization checks, not VR gameplay tests. No active-match late join is supported by the original networking flow; the host closes the room on match start.
