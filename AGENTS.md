# Cloudcourt repository instructions

- Read REPOSITORY-POLICY.md. Keep current release plus previous two, one V<number>/
  folder per release. Current: V30/, V29/, V28/. Advance that window every release.
- Source in each folder must match its own release. Preserve internal relative
  dependencies, original/verified licensed assets and notices.
- Root contains navigation and policy only; no accumulated old delivery files.
- Preserve local ZIPs/backups, sources/ references and Git history. No force push
  or history rewrite for routine cleanup.
- Publish source, delivery instructions and own/licensed art only. Keep reports
  and local metadata private. Never publish original game assets or binaries.
- Install only with the game closed. Never force-close a user's game.
- Local/native checks do not establish physical Quest 3 or real two-PC tests.
