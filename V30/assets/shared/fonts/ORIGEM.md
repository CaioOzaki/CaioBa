# Cloudcourt VR assets

Bots, gloves, court, net and menu card are procedural artwork created by this mod. The character meshes keep the locally installed game skeleton and animations; these original game files are not published here.

Baloo 2 is an open font from https://github.com/google/fonts/tree/main/ofl/baloo2 . Baloo2-Variable.ttf is the source; CloudcourtBubble.ttf is its static weight 800 instance. Redistribution includes Baloo2-OFL.txt. The Unity object name is Cloudcourt Bubble; the font family remains Baloo 2.

Menu composition created as editable text, components and vector shapes in Figma: https://www.figma.com/design/1sIgjKcMItHmbLIu1dnch0?node-id=2-24 . menu-figma.png is an exported preview, not an in-game screenshot.
