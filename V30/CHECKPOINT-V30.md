# Cloudcourt V30 - Polish fixes

For separately owned Volleyball Fever Steam build 9216628. Upgrade from V29 or
install over the compatible original. Keep the previous ZIP and recovery backup.
All online peers need V30; standard/Bomb and 2v2/4v4 rooms remain separate.

Requested repairs: guided drills and Bomb launch visibility; first Solo Extras;
customization mirror face/outfit textures; bot callouts above heads and slightly
louder calls; restore native controller vibration. Existing contact audio remains.
The match menu exposes Game/Sound settings, volume controls and a Back action.
Graphics remain in the main menu because changes require restarting the game.

The replacement playlist is three original lofi compositions synthesized locally
from oscillators and deterministic noise. No sampled songs/recordings are used.
See assets/audio-v30/CC0-NOTICE.txt. Music enable and volume preferences remain.

Native/desktop verification records are private local outputs. No physical Quest 3
or real two-PC multiplayer validation has been performed for this release.
No mini tournaments or unrelated new features are included.

Public repository policy: V30/, V29/, V28/ only, each matching its own source.
Historical Git commits, local ZIPs and backups remain preserved. Publish source,
instructions and own/verified licensed art only; no game binaries/assets/deltas.
